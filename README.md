# Проект "Ф" для банка "Эдельвейс"
## Проект "Ф" делает новую фичу для личного кабинета клиента, который показывает несколько успешных операций клиента
## Установка:
1. Клонируйте репозиторий:
```
https://github.com/MikhailNikolaev45732/pythonProject
```
2. Установите зависимости:
```
poetry init
popetry add requests
```
## Использование:
1. Откройте приложение в вашем веб-браузере
2. Создайте новый проект и начните добавлять задачи

## Тестирование:
1. Добавте в окружение пайтесты:
   poetry add --group dev pytest pytest-cov
2. Все тесты находятся в пакете tests и разбиты на модули
   соответствующие модулям программ в пакете src
