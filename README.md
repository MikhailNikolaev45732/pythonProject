# Проект "Ф" для банка "Эдельвейс"
## Проект "Ф" делает новую фичу для личного кабинета клиента, который показывает несколько успешных операций клиента
## Установка:
1. Клонируйте репозиторий:
```
https://github.com/MikhailNikolaev45732/pythonProject
```
2. Установите зависимости:
```
poetry init
popetry add requests
```
## Использование:
1. Откройте приложение в вашем веб-браузере
2. Создайте новый проект и начните добавлять задачи
## Новые функции:
   Описание функций смотри в docstring.
   Для использования функций и генераторов в модуле generators.py
   загружайте данные в файл transactions.txt, при использовании других файлов необходимо
   указать путь до используемого файла в функции.
## Новые функции:
   Написан код декоратора с параметрами в модуле decorators.py.
   Возможно использование декоратора с друкими функциями, вывод работы декоратора возможен как в консоль,
   так и с записью в выбранный файл .txt
   Тестирование декоратора см. "Тестироание:"
## Новые функции:
   Написан код для чтения табличных данных из файлов формата CSV в модуле reading_file_csv.py и из файлов
   формата EXCEL в модуле reading_file_excel.py. Информация из файлов выводится в консоль в виде списка словарей 
   формата JSON.
## Тестирование:
1. Добавте в окружение пайтесты:
   poetry add --group dev pytest pytest-cov.
2. Все тесты находятся в пакете tests и разбиты на модули
   соответствующие модулям программ в пакете src.
